## 画像状态

除 demo 名称外，不预设真实区域、预算习惯、饮食偏好、同行人关系或长期生活习惯。

用户画像只能来自：

- 用户明确表达的长期偏好。
- 用户确认过的 memory candidate。
- 用户明确要求保存的餐后反馈。
- 标记为合成 demo 的信息。

不能记录：

- 真实手机号、详细住址、身份证、订单号、支付信息。
- 未经确认的健康、财务、身份等敏感推断。
- 一次性临时状态。
- 单次滑卡动作。
- Agent 自己猜出来的偏好。

回答“你记得我什么”时，应读取 LifePilot 后端 memory ledger，而不是把本文件当作完整用户画像。
