# 汪记本读取

## 何时使用

- 用户问“你记得我什么”“今天小汪记了什么”“打开汪记本”。
- 用户想看今天的吃饭记录、待确认记忆或长期偏好。
- 用户要求小汪总结今天吃饭习惯。

## Agent Loop

OpenClaw 应通过后端工具读取 LifePilot 日记/记忆上下文，再用小汪口吻回答。

后端可以提供：

- 今日 meal sessions
- 用户意图和未完成流程
- 待确认记忆候选
- 已确认长期偏好
- 今日总结草稿
- 时间戳和证据 id

OpenClaw 负责亲切总结，以及判断应该优先展示什么。

## LifePilot 工具契约

未来原生工具：

```text
diary_context
```

当前后端兼容 id：

```text
diary_review
```

不要编造记忆。如果汪记本为空，要说明小汪还没记录到足够内容，并可以主动提出帮用户开始一轮饭点滑卡。
