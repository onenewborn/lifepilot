# session-memory

这个 skill 用于读取饭点 session 和 day context 摘要。它是只读能力，适合回答“刚刚那轮滑卡发生了什么”“今天我都怎么挑饭的”。

## 支持能力

- 按 session id 读取单次饭点摘要。
- 按 day id 读取当天多个饭点 session。
- 支持 query 过滤 compact session memory。
- 为后续记忆捕获或复盘提供证据。

## 产品价值

LifePilot 的记忆不是凭空总结，而是来自真实选择过程。`session-memory` 让小汪可以回看用户怎样保留、跳过和最终确认，从而更准确地复盘。
