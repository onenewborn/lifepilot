# merchant_reputation

这个目录保存商户口碑证据 seed。它为 `merchant-intel`、`merchant-compare` 和最终推荐解释提供评分、评论量级、好中差比例、口碑标签和特色菜等结构化信息。

## 支持能力

- 单店理解：回答“这家怎么样”“有什么特色菜”“适合一个人吗”。
- 多店对比：让小汪在证据基础上比较两到四家店。
- 风险提示：把排队、环境、油腻、踩雷等风险转成可解释字段。

## 产品价值

这个目录让 LifePilot 的 AI 判断更像“基于证据的生活建议”，而不是纯聊天模型的猜测。后端只提供证据，小汪负责用用户能理解的方式解释取舍。
