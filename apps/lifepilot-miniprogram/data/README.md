# data

这个目录保存小程序端需要随包携带的轻量数据。当前主要是方向卡视频 manifest，用来把后端返回的方向 ID 映射到 COS 上的视频和封面。

## 支持能力

- `video-manifest.js`：饭点方向卡视频清单，包含方向 ID、视频地址、封面地址、声音标记和版本号。

## 为什么放在小程序端

方向卡视频属于前端展示资产，和商户推荐逻辑不同。把 manifest 放在小程序端，可以让后端专注推荐和 session 状态，前端则负责选择合适的媒体呈现方式。

## 维护原则

- 只放小程序展示必需的轻量清单。
- 不放商户事实、评分、优惠、用户记忆等权威数据。
- 新增方向视频时，应保证 `directionId` 和后端方向数据一致。
