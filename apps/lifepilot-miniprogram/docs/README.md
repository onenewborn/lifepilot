# docs

这个目录保存微信小程序工程自己的调试和部署说明。它面向正在打开微信开发者工具、配置 API 地址、排查真机访问问题的人。

## 支持能力

- 说明小程序如何连接云端 LifePilot API。
- 记录微信开发者工具里和 request 域名、HTTPS 校验、真机预览相关的设置。
- 将前端运行排障和仓库级架构文档分开，避免使用者在全局文档里翻找小程序细节。

## 产品价值

LifePilot 的体验很依赖真实链路：小程序、后端、OpenClaw Gateway、Memory Intelligence 都要配合工作。这里的文档让演示和调试更可重复，减少“代码没问题但设备连不上”的时间损耗。
