# meal

这个目录是微信小程序的主页面，也是 LifePilot 用户体验最核心的地方。它把“问小汪”“挑饭”“汪记本”放在同一个饭点场景里，让用户从模糊需求走到可解释的选择结果。

## 支持功能

- 问小汪聊天：用户可以直接说“今天吃什么”“想吃川菜”“这家有优惠吗”。
- 饭点滑卡：支持方向卡、商户卡、左右滑反馈、方向小结和最终确认。
- 商户媒体展示：支持图片、视频、封面、多视频来源、弹幕式短句和视频错误兜底。
- 汪记本：展示今日小结、本周小结、食物选择画像、待确认记忆和已确认偏好。
- 手动复盘：支持今日复盘和本周复盘，触发后端 Memory Intelligence。
- 会话恢复：通过本地 storage 恢复当前饭点 session，减少刷新后丢状态。

## 产品亮点

这一页体现了 LifePilot 的核心优势：AI 不是直接替用户下结论，而是陪用户做决定。滑卡行为、聊天表达、最终确认和餐后反馈都会成为后续个性化的证据。汪记本让这些证据透明可见，用户可以确认或拒绝系统总结出来的偏好。

## 文件职责

- `meal.js`：页面状态机、后端调用、聊天轮询、滑卡动作和复盘触发。
- `meal.wxml`：页面结构和数据绑定。
- `meal.wxss`：视觉样式、卡片布局、聊天和汪记本样式。
- `meal.json`：页面级小程序配置。

## 维护提醒

这个页面已经承载了很多主线能力。后续大改时应优先拆出更小的 controller 或组件，而不是继续把所有逻辑堆在单个页面文件里。
