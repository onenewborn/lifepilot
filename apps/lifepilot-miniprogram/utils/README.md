# utils

这个目录保存小程序端可复用的展示和交互工具。它们不拥有业务状态，只负责把后端数据变成前端更容易渲染的结构，或提供稳定的手势/格式化函数。

## 支持能力

- `card-normalizer.js`：把方向卡、商户卡、最终结果和优惠信息归一化为页面可直接使用的字段。
- `swipe-gesture.js`：计算左右滑时的卡片位移、旋转和反馈样式。
- `format.js`：文本压缩、标签截断和金额展示。

## 产品价值

LifePilot 的推荐不是普通列表，而是高度视觉化的卡片体验。工具层让页面可以专注交互，把媒体、标签、解释、优惠、路线和最终确认这些复杂字段变成稳定的 UI 数据。

## 维护原则

- 工具函数应保持纯粹，尽量不依赖页面状态。
- 归一化可以兼容旧字段，但新业务字段应优先以后端合同为准。
- 不在这里读取远程 API 或修改用户记忆。
