# config

这个目录保存小程序运行时的配置入口，主要用于区分后端 API 地址和静态资产地址。它让小程序可以在本地开发、云端演示、临时排障之间切换，同时避免把地址散落在页面代码里。

## 支持能力

- `api.js`：定义 API 访问模式，包括本地、局域网、云端和临时 tunnel。
- `assets.js`：定义 COS 静态资产 base URL，并提供统一的资产 URL 拼接函数。

## 当前默认模式

比赛评审阶段默认使用云端后端：

```js
const API_MODE = "cloud";
const CLOUD_API_BASE_URL = "http://110.42.208.125";
```

如果自己部署后端，需要把 `CLOUD_API_BASE_URL` 改成自己的服务器地址。开发者工具本地联调可以改成：

```js
const API_MODE = "local";
```

这会访问：

```text
http://127.0.0.1:4331
```

## 产品价值

LifePilot 依赖真实的后端和媒体资源来完成饭点体验。配置集中管理可以让演示和开发更加稳定：小程序页面不用知道当前连接的是本机、云服务器还是临时排障地址，只要使用 service 层即可。

## 维护原则

- 默认配置应优先服务当前主链路。
- 临时 tunnel 可以保留为排障选项，但不应作为默认入口。
- 资产地址只做拼接和归一化，不在这里写业务规则。
