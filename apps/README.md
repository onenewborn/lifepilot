# apps

这个目录存放 LifePilot 的用户端应用。当前主线只有微信小程序 `lifepilot-miniprogram`，它承载“问小汪、挑饭、汪记本”三个入口，是评委和真实用户最直接接触到产品价值的地方。

LifePilot 的优势不在于把后端接口简单包成页面，而是把 AI 推荐做成可参与的生活决策体验：用户可以先和小汪对话，再进入滑卡流程，最后在汪记本里看到系统如何理解自己的选择。前端的职责是让这条闭环变得轻、顺、可感知。

## 当前内容

- `lifepilot-miniprogram/`：微信小程序主工程，当前唯一正式应用。

## 设计边界

- 应用端只负责展示、交互和轻量状态恢复。
- 饭点 session、推荐排序、记忆账本、Memory Intelligence 结果都以后端为准。
- 新增应用时应保持和主产品 runtime 的边界清晰，不要把后端规则或 OpenClaw workspace 逻辑复制到前端。
