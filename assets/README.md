# assets

这个目录用于存放本地静态资产或后台上传资产的仓库侧占位。当前主产品的大部分图片和视频通过腾讯云 COS 加载，小程序端由 `config/assets.js` 统一拼接远程 URL。

## 支持能力

- 为本地后台管理上传或测试资产提供落点。
- 保留与 `/assets/...` 路径一致的目录结构，方便后端静态服务和数据文件引用。

## 产品价值

LifePilot 的滑卡体验依赖真实、有食欲感的媒体素材。资产目录和 COS 配置共同支撑“商户卡不是冷冰冰列表，而是可感知的吃饭候选项”这一产品体验。

## 维护原则

- 大体积视频和正式图片优先放 COS，不直接提交进仓库。
- 本地资产应保持命名清楚，能对应商户、方向或后台上传来源。
- 不把运行时缓存、生成中间产物或私密素材放进仓库。
