
旧的独立 Dreaming 系统已删除：

```text

/api/openclaw/run-dream                   已移除，云端返回 404
```

新的统一入口：


### 5. 记忆账本

后端记忆权威是本地 JSON runtime，不再依赖 Evermind。

主要概念：

```text
memory_observations       原始观察
memory_candidates         待确认候选记忆
confirmed_preferences     用户确认后的长期记忆
food_insight_profile      食物选择画像
recommendation_signals    快速推荐可执行 signals
memory_intelligence_jobs  复盘和记忆加工 job
```

汪记本现在只读取：

```text
memory_intelligence_jobs
```

没有当天 job 时，才使用 day_context 和 memory ledger 生成规则摘要。

## 已知风险和注意事项

1. 问小汪所有聊天都走 OpenClaw Gateway client。简单 hello 也不走本地兜底，这是产品要求。
2. OpenClaw 请求有时仍会慢，云端直连“川菜有什么推荐吗”曾测到约 40 秒返回。小程序前端如果显示 2-3 分钟无响应，需要继续区分是 OpenClaw 慢、微信请求 timeout，还是前端状态没有正确收尾。
3. 小程序里 COS 视频偶尔报 `Failed to load media ... devtools_no_referrer`，这更像微信开发者工具/COS referer 或媒体加载问题，不影响后端推荐主链路，但正式演示前要单独确认素材能稳定播放。
4. `api.lifepilot-xiaowang.cn` 域名方向已经讨论过，但比赛前备案来不及。当前更稳的是小程序连接 `http://110.42.208.125`。
5. 不要再恢复旧 Dreaming 系统。后续复盘、画像、signals 都应继续放到 Memory Intelligence 里。
6. 云端 `/root/.openclaw/workspace` 和 GitHub 里的 `openclaw-workspace/` 要保持同步，否则本地看起来改了 skill，真实 agent 可能仍读旧文档。
7. 云端 `/opt/lifepilot` 不要手改产品代码；改动应从 GitHub main 拉取。

## 下一步建议

```text

2. 如果问小汪仍卡很久，继续查 OpenClaw Gateway 日志和小程序 timeout 配置。
```
