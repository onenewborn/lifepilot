# archive

这个目录保存历史交接、迁移阶段记录和旧接口说明。它们对理解项目来路有价值，但不再作为当前开发主线的首要依据。

## 包含内容

- 旧交接和阶段状态。
- 迁移期接口映射。
- 已被 Memory Intelligence 替代的旧 OpenClaw job 说明。

## 使用方式

如果你需要理解“为什么现在是这个架构”，可以读这里。如果你要判断当前应该怎么开发、部署或调试，应优先看根 README、最新 handoff、`docs/contracts/` 和 `openclaw-workspace/` 的当前规则。

## 维护原则

- 不在归档文档里继续维护最新状态。
- 如果历史文档和当前代码冲突，以当前代码和非归档合同为准。
